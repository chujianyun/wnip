# 贴图

- 截图选区确认后按 `Cmd+Shift+P`，或点击工具栏的图钉按钮，把当前截图固定在其他普通窗口上方。
- 截图中的绘图、马赛克和正在编辑的文字都会包含在贴图中。
- 已复制或保存截图后，也可以按 `Cmd+Shift+P`，或使用菜单栏的 `Pin Screenshot`，贴出本次运行中最近一张截图。
- 鼠标按住图片可拖动位置。点击左上角关闭按钮可关闭；选中贴图后也可以按 `Esc`。
- 可以同时保留多张贴图，各自移动和关闭。退出 Wnip 后清除贴图和最近截图缓存。
- 直接贴图不修改剪贴板，也不自动保存文件。
- 贴图保持 Retina 点尺寸；超过显示器可用区域时等比例缩小。每张贴图跨桌面显示，并支持全屏应用所在桌面。
- `Cmd+Shift+P` 是固定的贴图快捷键，截图快捷键设置不能占用它。快捷键录制期间暂停全部全局快捷键。
