# Wnip macOS 截图软件设计规格

## 1. 项目目标

研发一款原生 macOS 截图工具，视觉与交互参考 `protetype/` 中的原型图。首版聚焦截图、标注、复制、保存和偏好设置，不实现滚动截图、购买、订阅或任何付费限制。

应用最低支持 macOS 15 Sequoia，采用 Swift、SwiftUI、AppKit 和 ScreenCaptureKit，不兼容更早版本。

## 2. 首版范围

### 2.1 截图模式

- 自由框选区域截图。
- 悬停高亮并点击选取单个窗口。
- 当前显示器全屏截图。
- 支持多显示器，并正确处理不同缩放比例和屏幕坐标系。

### 2.2 标注工具

- 矩形、椭圆、直线、箭头。
- 自由画笔、马赛克、文字、高亮。
- 自动递增的步骤编号。
- 撤销操作、取消截图、保存截图、复制到剪贴板。
- 绘图工具支持适用的颜色、线宽和字号配置。
- 截图完成后允许拖动选区边缘再次裁剪。

### 2.3 明确不做

- 滚动截图。
- 购买页、订阅、内购、许可证校验或付费功能限制。
- 云同步、团队协作、OCR、录屏和移动端版本。

## 3. 用户流程

1. 应用启动后常驻菜单栏，并注册区域截图全局快捷键 `⇧⌘X`。
2. 用户从快捷键或菜单选择区域、窗口或全屏截图。
3. 应用检查屏幕录制权限。没有权限时显示说明并引导用户前往系统设置。
4. 每块显示器创建无边框透明浮层，展示暗色遮罩和当前选区。
5. 区域模式允许拖拽选区；窗口模式随鼠标悬停高亮候选窗口；全屏模式选择当前鼠标所在显示器。
6. 截图完成后冻结画面，显示可编辑选区和悬浮标注工具栏。
7. 用户可以标注、撤销、再次裁剪，然后复制、保存或取消。
8. 输出成功后按设置发送通知、播放提示音并关闭所有截图浮层。

按 `Esc` 取消当前截图；在编辑阶段使用 `⌘Z` 撤销。截图会排除本应用自己的遮罩、工具栏和设置窗口。

## 4. 技术架构

### 4.1 应用外壳

使用 SwiftUI `App` 管理生命周期、菜单栏入口和偏好设置窗口。需要精确控制窗口层级、跨屏覆盖、鼠标事件或键盘事件的界面使用 AppKit 实现。

应用由以下边界清晰的模块组成：

- `AppShell`：应用生命周期、菜单栏菜单和命令分发。
- `CaptureCoordinator`：维护截图会话状态，协调权限、捕获、浮层与输出。
- `ScreenCaptureService`：封装 ScreenCaptureKit，枚举屏幕与窗口并生成位图。
- `OverlayController`：为每个显示器创建和销毁透明浮层窗口。
- `SelectionModel`：处理框选、调整尺寸、坐标转换和模式切换。
- `AnnotationCanvas`：呈现标注并把用户输入转换为可撤销的标注命令。
- `ImageRenderer`：将原始截图、裁剪区域、阴影和标注合成为最终图片。
- `OutputService`：负责编码、文件命名、保存和剪贴板写入。
- `PreferencesStore`：基于 `UserDefaults` 保存设置。
- `PermissionService`、`HotKeyService`、`LaunchAtLoginService`：分别封装系统权限、全局快捷键和登录项。

各服务通过协议暴露能力，使坐标计算、文件输出和会话状态可以脱离系统 UI 进行单元测试。

### 4.2 截图实现

ScreenCaptureKit 负责获取可共享的显示器、应用和窗口内容。窗口截图通过窗口标识捕获目标窗口；区域和全屏截图先捕获目标显示器，再按照 ScreenCaptureKit 像素尺寸与 AppKit 点坐标的转换结果裁剪。

截图开始前先取得候选窗口列表并过滤本应用、桌面元素、不可见窗口和尺寸异常窗口。浮层仅展示交互状态，不参与最终输出。

### 4.3 会话状态

截图会话采用显式状态机：

`idle → requestingPermission → selecting → editing → exporting → completed`

任意活动状态都可以转为 `cancelled`；权限、捕获或输出失败进入 `failed`，清理所有浮层后向用户展示可恢复的错误信息。一次只允许存在一个截图会话，重复快捷键会结束旧会话并启动新会话。

## 5. 界面设计

### 5.1 截图浮层

- 选区外使用半透明深色遮罩，选区使用蓝色描边与八个调整手柄。
- 左上角显示选区像素尺寸。
- 窗口模式悬停时高亮完整窗口边界。
- 截图确认后，白色圆角工具栏优先位于选区下方；空间不足时自动放置到上方或选区内部。
- 多显示器上只有当前交互屏展示完整工具栏，其他屏保留遮罩。

### 5.2 标注交互

标注对象保留矢量模型，最终输出时统一栅格化。每次新增、修改、删除或裁剪都作为可撤销命令进入撤销栈。马赛克仅对其覆盖范围内的原始截图做像素化处理，不破坏源图。

步骤编号从 1 开始，创建后自动递增；撤销并重新添加时使用当前画布上可见编号的下一个值。

### 5.3 菜单栏

菜单包含：

- 区域截图。
- 窗口截图。
- 全屏截图。
- 偏好设置。
- 退出 Wnip。

关闭菜单栏图标时应用仍可通过全局快捷键运行；设置窗口提供恢复显示菜单栏图标的操作，避免用户失去入口。

### 5.4 偏好设置

偏好设置仅保留“通用”页面，不显示购买标签。设置项包括：

- 登录时启动。
- 区域截图阴影与窗口截图阴影。
- 完成通知与提示音。
- 默认格式 PNG 或 JPEG；JPEG 质量。
- 菜单栏图标。
- 鼠标振动反馈。
- 区域截图全局快捷键录制。
- 文件命名规则。
- 默认保存目录。

默认命名规则为 `Wnip-yyyy-MM-dd_HH-mm-ss`。默认保存目录未指定时，首次保存显示系统保存面板；用户选定目录后记住该目录。目录访问权限使用安全作用域书签持久化。

## 6. 输出规则

- PNG 保留透明度；JPEG 使用用户设置的编码质量，默认 90%。
- 区域截图默认不加阴影；窗口截图默认添加符合 macOS 视觉习惯的柔和阴影。
- 全屏截图不添加阴影。
- “复制”写入最终合成图后结束截图会话。
- “保存”写入默认目录；没有默认目录时显示保存面板。
- 文件名冲突时追加 `-2`、`-3`，不覆盖已有文件。

## 7. 权限与错误处理

- 屏幕录制权限缺失：解释用途，提供打开“隐私与安全性 > 屏幕与系统音频录制”的按钮，并提供重新检测。
- 快捷键冲突：保留原快捷键并提示用户重新录制。
- 保存目录失效或不可写：显示保存面板选择新位置，不丢失当前编辑内容。
- 编码或剪贴板写入失败：停留在编辑状态，展示错误并允许重试。
- 显示器在会话中断开：安全取消对应浮层；如果目标显示器已断开，则保留编辑画面或提示重新截图。

## 8. 数据与隐私

截图和标注均在本机内存中处理，不上传网络。除用户明确保存或复制的结果外，不保留截图缓存。偏好设置只保存配置、快捷键和目录安全书签。

## 9. 测试与验收

### 9.1 自动化测试

- `SelectionModel`：正反方向拖拽、边界约束、最小尺寸及跨屏坐标转换。
- 截图状态机：正常流程、取消、重复启动及各阶段错误恢复。
- 标注模型：工具参数、对象命中、步骤编号和撤销栈。
- `ImageRenderer`：裁剪尺寸、Retina 比例、标注合成、马赛克与阴影。
- `OutputService`：PNG/JPEG 编码、命名规则、冲突处理和错误返回。
- `PreferencesStore`：默认值与持久化。

实现采用测试驱动流程：每项核心行为先写失败测试，确认失败原因正确，再实现最小代码并运行完整测试集。

### 9.2 手动验收矩阵

- 单显示器与多显示器。
- Retina 与非 Retina、不同缩放比例、显示器上下左右排列。
- 区域、窗口和全屏三种截图模式。
- 普通窗口、带阴影窗口、全屏应用及多个桌面空间。
- 屏幕录制权限首次拒绝、之后授权和权限撤销。
- 全部标注工具、撤销、再次裁剪、复制和两种格式保存。
- 菜单栏、登录启动、全局快捷键冲突及设置重启后保持。

### 9.3 首版完成标准

- 三种截图模式均可从菜单栏启动，区域截图可从 `⇧⌘X` 启动。
- 输出图片不包含 Wnip 自身界面，坐标与 Retina 像素尺寸正确。
- 原型列出的非滚动截图标注工具均可使用，并可撤销。
- PNG/JPEG 保存、复制到剪贴板、通知和提示音按设置工作。
- 设置在应用重启后保持。
- 自动化测试通过，并完成上述手动验收矩阵。
