## API 依据

- [Apple：SCShareableContent.windows](https://developer.apple.com/documentation/screencapturekit/scshareablecontent/windows) 只描述可用窗口列表，不承诺前后层级；层级使用本机 WindowServer API 获取。
- [Apple：ignoreShadowsSingleWindow](https://developer.apple.com/documentation/screencapturekit/scstreamconfiguration/ignoreshadowssinglewindow) 用于去掉单窗口系统阴影，避免源图与窗口 frame 错位。
- [Apple：includeChildWindows](https://developer.apple.com/documentation/screencapturekit/scstreamconfiguration/includechildwindows) 在单窗口采集配置中关闭；屏幕采集配置保持原行为。
